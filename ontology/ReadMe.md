# Ontology Archive

`i-adopt.ttl` is the currently maintained version of the ontology. Please edit this one for merge requests. I-ADOPT variables should conform to this ontology schema and satisfy the validation constraints specified in the [I-ADOPT SHACL shape definitions](https://raw.githubusercontent.com/SirkoS/iadopt-schema/main/shacl/iadopt.sh.ttl).

All other files that include the version in their name are kept for documentation purposes.

The [extended version](https://raw.githubusercontent.com/i-adopt/ontology/main/ontology/i-adopt_extended.ttl) incorporates formal class definitions and logical restrictions.
